# G16 exception list — the ONLY way an NFR-24 table may ship unpartitioned.
#
# NFR-24 says "No exceptions", and this file does not weaken that: it makes the
# exceptions that exist in the running code VISIBLE, ATTRIBUTABLE and EXPIRING.
# An entry is a parked decision, never a granted one. G16 fails if the cited
# open question is CLOSED (the reason to be unpartitioned has expired — ship the
# ruling), if the OQ does not exist, if the OQ's registry row does not name the
# table, or if the table has since been partitioned (stale entry — delete it in
# the same diff that partitions the table).
#
# One entry per line, four fields:
#   <table> <OQ-### | PO-RULED> <YYYY-MM-DD added> <reason: who reported it, and what closes it>
#
# The second field says WHAT KIND of exception this is, and the two are not
# interchangeable:
#   OQ-###    PARKED. A question is open; when it closes, this line must go —
#             either because the ruling was to partition, or because it was
#             ratified and the line is re-filed as PO-RULED.
#   PO-RULED  RATIFIED. The PO decided this table stays unpartitioned. It does
#             not expire. Reopen only by a new ruling, never by editing here.
#
# The distinction exists because OQ-108 closed IN FAVOUR of the exception, and
# the gate then failed a line whose reason had not expired but had been signed.
#
# Adding a line here is a process event — it goes into the daily PO batch like an
# E1 (B12 r2, "who watches the watchers"), same as editing human_owned.txt. You
# are recording that shipped code disagrees with signed law; do not add one
# without an open question that says so.

# the two lawful outcomes this file's own header names. Neither was re-filed as
