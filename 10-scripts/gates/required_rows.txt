# G26 — REQUIRED PER-TENANT ROWS. One record for every row a money path REFUSES
# without, together with the thing that can actually put it there. DEF-123: a
# row nothing creates is a money path nothing can complete, and the register is
# how that stops being invisible.
#
#   <table> | <refusal file::function> | <phrase> | <kind> | <writer file::symbol> | <wired file::kind:name> | <reason>
#
# phrase — a distinctive substring of the refusal's own sentence. It is the
#   STALENESS anchor: if the refusal is reworded or deleted, this row is fiction
#   and the gate says so rather than letting a dead entry vouch for a live table.
#
# kind — how the row comes into existence, and each is checked differently:
#   provisioning   a seeder runs at signup. Checked: the writer is DEFINED, and
#                  it is CALLED (an AST call site, not a mention in a comment).
#                  This is DEF-123's exact hole — the writer did not exist at
#                  all, and nothing anywhere asked.
#   migration      a migration plants it. Checked: the file exists.
#   endpoint       a human creates it through a MOUNTED route. Checked: the view
#                  is defined, it appears inside a `path(...)` in its own module,
#                  and that module's urlpatterns are included by config/urls.py.
#                  An unmounted view is DEF-123 again: `templates_service` had a
#                  complete create-and-publish lifecycle and S8's Templates tab
#                  had no endpoint, so no human could reach it either.
#
# A row whose money path refuses and whose kind is NONE OF THESE does not belong
# here — it belongs in the defect log.
