# G33 BASELINE — refusal messages that were already over SIX words on the day
# six became the rule. 598 of them, measured 2026-08-31. IT MAY ONLY SHRINK.
#
# PO ruling 2026-08-30, verbatim: "Refusal copy is short - your 12-word ruling -
# this shuld be 6 words only - not too long; this family BORN ASPIRATIONAL it
# cannot be ASPIRATIONAL any more - there are so many bugs becuase of this."
#
# The two halves of that ruling pull against each other and this file is how
# both are honoured. Re-measured 2026-08-31 over all 850 English refusal
# messages: 817 pass at twelve words (96%) and 252 pass at six (30%). Setting
# six with no baseline would take this gate from 96% passing to 30% passing --
# a backlog of 598 wearing a gate's clothes, which is the exact "BORN
# ASPIRATIONAL -> NEVER GREEN" shape the second half of the ruling forbids.
#
# So: SIX IS THE RULE FROM TODAY and it binds every NEW or CHANGED refusal.
# The 598 already here are parked, one per line, and the file may only shrink.
# The project of rewriting them is DEF-2606 -- 598 messages across eleven
# catalogues, worked down a lane at a time, never all at once.
#
# ONE LINE PER MESSAGE:  <key> :: <the English text, whitespace normalised>
#
# ⚠ THE TEXT IS PART OF THE IDENTITY, ON PURPOSE. The ruling binds every new or
# CHANGED refusal, so editing the English makes the line stop matching and the
# message owes six words. A baseline keyed on the key alone would let a message
# be rewritten and stay long forever, which is decoration and not a ratchet.
#
# ⚠ AND WHEN YOU SHORTEN ONE, SHORTEN BY DELETING THE RATIONALE, NEVER THE
# INSTRUCTION. Two sentences of six beat one sentence of twelve. Cutting the
# sentence that says what to do next PASSES the gate and makes the message
# useless -- nothing downstream can catch that. Move the reason into the code
# comment beside the string. All eleven catalogues move together (G15).
#
# TO RETIRE A LINE: shorten the message in all eleven catalogues and delete the
# line in the SAME diff. G33 reports a stale line on every run until you do.
