# G129 BASELINE — premises/units strings that were still over B14 rule 33's
# caps on 2026-09-19, after the sweep that DEF-MET-5836 records. IT MAY ONLY
# SHRINK.
#
# THE SWEEP THAT PRODUCED THIS FILE. 218 strings were over the caps that
# morning, 2,551 words in all. 122 were rewritten and 8 retired across all
# eleven catalogues; the longest string on any premises or units screen went
# from 47 words to 17, and the worst of what remains is a note behind a
# collapsed disclosure. These are what was DELIBERATELY NOT CUT, and the
# reason is per class rather than per line:
#
#   * 39 LABELS over three words. Most are empty-state titles and row actions
#     ("Nothing is installed here yet", "+ Add a common area"). B14 rule 4
#     gives an action its own grammar and the blueprint draws several of these
#     headings by name, so shortening them is a DRAWING question (rule 38:
#     what a form CONTAINS is the drawing's to decide), not a copy sweep's.
#
#   * 39 strings at SEVEN words — one over. Rule 33's own framing is that the
#     caps "codify what the good strings already do… rather than imposing a
#     target nobody meets", and its consequence clause says NEVER CUT BELOW
#     CLARITY. Taking "Start typing. We look it up." style lines down one more
#     word is churn against eleven catalogues for no reader benefit.
#
#   * 4 notes behind a CLOSED DISCLOSURE on the common-areas tab
#     (`common.masterCallout` and the three `*ArrivesWith`). B14 rule 32 says a
#     stated absence is a `<details>` CLOSED by default, and these already are
#     — `CommonAreasTab.tsx` says so in its own comment. They cost a clerk
#     nothing to skip, and each one CITES the question that will kill it
#     (`OQ-314`, `OQ-327`, `DEF-560`), which G38 checks. Rewriting them would
#     drop citations that were deliberately preserved.
#
#   * 2 ROLL-UP LINES (`rollupLine`, `rollupLineCommon`). These are four
#     counts joined by `·` — a chip list, not a sentence, and the word counter
#     reads the whole run as one. ⚠ The real question about them is not length:
#     the blueprint for this screen says "No roll-up sentence is drawn. The
#     line under the title is the subtitle", and the screen draws the roll-up
#     in that slot. That is a CONFORMANCE question, reported rather than taken,
#     because removing the counts changes what a clerk can see.
#
# FORMAT: `<key> :: <the English text, whitespace normalised>`, exactly as
# G33's baseline. THE TEXT IS PART OF THE IDENTITY — change the copy and the
# licence lapses, so a line cannot be rewritten and kept long forever.
