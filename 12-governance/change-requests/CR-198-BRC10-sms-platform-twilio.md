## 5 · Operational prerequisites (DevOps / business — NOT code)
1. **A2P 10DLC (US).** Register the platform brand and one campaign per use case (and per utility where its texts must come from its own number) in the Twilio console; attach each campaign to a **Messaging Service**. Unregistered 10DLC traffic is filtered by US carriers. Until approved, use a toll-free number (also needs verification) or expect filtering.
2. **Twilio Advanced Opt-Out** on each Messaging Service: keep STOP / START / HELP enabled at Twilio — **we build STOP only** (PO: *"ONly Stop option is required"*); Twilio answers HELP and START at the carrier level.
3. **The reply webhook**: on each Messaging Service set *Incoming messages → Send a webhook* to `{PUBLIC_API_BASE_URL}/api/hooks/twilio/reply` (POST).
4. **Server secrets**, in each server's OWN environment — ⚠ **law 4: an existing `.env` does NOT get these from `.env.example`**; add them by hand to `06-backend/.env` (or the task definition / secret store) on **sandbox AND production**:
   - `TWILIO_ACCOUNT_SID` (AC…), and either `TWILIO_AUTH_TOKEN` or `TWILIO_API_KEY_SID` + `TWILIO_API_KEY_SECRET` (the Auth Token is still needed to check callback signatures — without it callbacks are refused);
   - `TWILIO_MESSAGING_SERVICE_SID` (MG…, preferred) or `TWILIO_FROM_NUMBER` (+E.164) — the platform default sender;
   - optional `TWILIO_SENDER_BY_UTILITY` — `subdomain:MG…;subdomain2:+1…`;
   - `PUBLIC_API_BASE_URL` — the API's public origin (e.g. `https://api-sand.bynry.com`), no trailing slash. **The PO supplies the per-server values from DevOps.** Unset ⇒ no StatusCallback is requested and the card says so.
