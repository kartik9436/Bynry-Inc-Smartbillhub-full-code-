# Metrics
Weekly numbers cited by the WSR:
- golden-tests: pass / xfail / skip counts (target: all pass after finance sign-off)
- A17 burn-down: blocking items remaining (target: 0 before billing code)
- isolation suite: pass rate (only acceptable number: 100%)
- open S1/S2 defects (release gate: 0)
- spec-vs-build drift: screens shipped vs A1 inventory
