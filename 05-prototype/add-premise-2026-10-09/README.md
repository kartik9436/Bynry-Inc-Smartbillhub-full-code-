Change request: `12-governance/change-requests/CR-177-BRC10-add-a-premise-redesign.md`.
Desktop only, 1440 wide, full page. **The dashed "Design mock-up" demo bar at the top and the "What this design fixes" table at the bottom are NOT product**; the table is kept in the HTML because it lists every text change.

**How to use:**
- Build the screen from its IMAGES (B14 rule 42). The HTML and this index are an index, never the specification.
- The images decide WHAT is on the screen and HOW it is arranged; our UI standard decides spacing, sizes, type scale, tokens and components, every time (B14 rule 44). The mock-up's own colours and fonts are not our style.
- Every figure in an image is an ILLUSTRATION (B14 rule 37): `P-00086`, Avenel NJ, Bramble Property Group, `AC-2026-00031`, Roof age, the parcel and the point. Real figures come from the data.
- **Superseded inside the images, and the later ruling wins:** none.
