The header, part by part

  • Back link to the list it came from.
  • Kicker: the build number and the request it came from — the two numbers a clerk reads out.
  • Title: the premise name, because that is what people call the build.
  • Roll-up: address, unit count, who raised it and when, the service chips, the state.
  • Actions: a More menu holding the other seven acts, and one primary act. No Open premises or Open account — the Overview table already links both, and a link in two places is one that goes stale in one of them.
  • Tabs sit in the header, as on every other detail page.

Why the acts moved into More

  • Eight buttons in a row is not the product’s header. One primary act plus a menu is.
  • Every act is one or two words, on your instruction of 28 Sep.
  • In the menu: Hold, Release, Waiting on, Add service, Mark outstanding, Close outstanding, Cancel build.
  • A greyed item says why, from the same check the server uses.
  • ? Say if you would rather the primary act were something other than Raise order.

The list, revamped

  • Every build number opens its own page. A draft opens the draft page, which is what changes from today.
  • The tiles filter. Clicking one narrows the table, which is what four counts sitting above a table should do.
  • No saved-view chips. State is a filter, and the same choice in two controls is how two screens end up disagreeing. Open, Drafts, Waiting, Done and Cancelled all live under Filter.
  • Money is on the list for the first time, because a build now raises an invoice. Due is what is still owed.
  • Aging goes red past a threshold, the same as the Accounts list. 41 days is the one to look at.
  • Columns chooses the rest: charged, mode, scope, raised by, request number, last event.
  • The row menu holds Hold, Waiting on and Cancel build; the tick boxes do the same in bulk.
  • Search covers build, premise, address, customer and request number. It already does; the placeholder now says so.
  • The table, filters, sorting and paging are the ones the Accounts list already uses, and paging is done by the server.
