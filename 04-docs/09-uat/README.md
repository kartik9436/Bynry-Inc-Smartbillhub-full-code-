# UAT — User Acceptance Testing
Per-module UAT scripts written in operator language (the audience is a 1–2-person utility staff, not engineers).
Each script: preconditions → numbered steps ("click", "type", "you should see") → pass/fail per step → sign-off block.
Scripts are authored by QA as each module completes (see 04-docs/06-roles/qa-lead.md) and named uat-<module>.md.
