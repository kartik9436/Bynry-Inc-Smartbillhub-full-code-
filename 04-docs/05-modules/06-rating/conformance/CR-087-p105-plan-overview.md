### Findings

1. **⚠ THE TILE ROW IS THE WRONG FOUR, IN THE WRONG ORDER, AND THE `NOT WORKED OUT
   YET` BAR DOES NOT EXIST.** `PlanDetail.tsx:661-701` builds:

   | # | code | drawn |
   |---|---|---|
   | 1 | `Units` / `detail.accounts` / *"on this plan today"* | **`UNITS`** ✓ |
   | 2 | `Revenue` / `"—"` / *"Nothing adds up what this plan has billed…"* | **`SERVICES`** |
   | 3 | `Services` / count / names | **`MONTHLY BASE`** |
   | 4 | `Exceptions` / `"—"` / *"Waivers granted and tax exemption certificates…"* | **`CHANGE ALREADY DATED`** |

   So **two of the four tiles are stated absences drawn as `—`**, which is exactly
   what the frame moves off the tile row into a labelled bar, and **the two figures
   the frame puts on the tile row — the monthly base and the dated change — are on no
   tile at all.** `detail.base_charges` is served (`selectors.py:478`) and is drawn
   only as a `Field` inside `What this plan is` (`PlanDetail.tsx:966-972`); the dated
   change is drawn only in the banner (`PlanDetail.tsx:793-810`).
   The third absence sentence, `kpi.accountsAbsent`, is a bare `<Note>` at
   `PlanDetail.tsx:1060` — at the FOOT of the tab, below the card and the accounting
   panel, with no label and no companion. The frame's `NOT WORKED OUT YET` bar groups
   all three under one label directly beneath the tiles.
2. **THE `HELD` CHIP IS NOT VISIBLE.** `PlanDetail.tsx:747-749` renders
   `<Button disabled title={t("rating.planDetail.action.duplicateHeld")}>` — the
   reason rides on the `title` attribute only. The frame draws `HELD` as a small chip
   INSIDE the button beside the label. A `title` is a hover tooltip and reaches no
   keyboard user and no screen reader reliably; B14 rule 15's "icons WITH TOOLTIPS"
   covers row-action icons, not a held header button. Recorded.
3. **THE TAB DESCRIPTION IS NOT THE DRAWN SENTENCE.** Drawn
   `Everything this plan charges, on one page.`; code
   `rating.planDetail.explainer.overview` = *"What this plan is, and what a customer
   is told it is."* (`PlanDetail.tsx:658`, `en.json`). That sentence described the
   Overview tab **before** the seven merges, when the tab really did hold only the
   identity block. The Units and Audit explainers are both verbatim to their frames.
4. **`What this plan is` HOLDS THE WRONG FIVE FACTS.** `PlanDetail.tsx:950-973`
   renders `Plan` (the name, already the H1) · `Code` · `Services` (the count,
   already tile 2) · `Budget billing` · `Minimum bill` (already Band 5) ·
   `Base charges` (the frame's tile 3), then the description as a plain `Field`.
   Against the drawn five:

   | drawn | present? |
   |---|---|
   | `CODE` | ✓ |
   | `CUSTOMER CLASS` | ✗ — nowhere on this panel |
   | `RUNS` | ✗ — the range is in the header sub-line only |
   | `BUDGET BILLING` | ✓ |
   | `MEANT FOR` + *"Any account can be assigned to it."* | ✗ — the equivalent is in the separate `Intended for` panel, as `audienceLabel`/`audienceUnset` (`PlanDetail.tsx:1237-1241`) |
   | `WHAT CUSTOMERS ARE TOLD` callout | ✗ — the description is a plain `Field`, not a callout |

5. **THREE PANELS ARE ON THE TAB THAT THE FRAME DOES NOT DRAW.**
   * `Sample bill` — `PlanDetail.tsx:1013-1020`, heading + `sampleBill.unavailable`.
     The frame puts the specimen-bill absence on **step 8** only.
   * `Where the money is posted` — `PlanDetail.tsx:1022-1047`, one GL field per

7. **THE SEVEN-LIMITS PANEL'S SENTENCE IS NOT THE DRAWN ONE.** Drawn

## CONTRADICTIONS FOUND IN THE BLUEPRINT — recorded, not resolved

1. **`$20.0000` ON THE `MONTHLY BASE` TILE.** Four decimals, on the same page whose
   RULES row reads *"Money shows two decimals and is stored to four"*, and against
   CLAUDE.md hard rule 2. The served value **is** four-decimal
   (`selectors.py:478`, `_money`), so the frame appears to have drawn the raw
   response. **Read as: the tile shows two, and the drawn figure is B14 rule 37's
   illustration.** No lane may "fix" a two-decimal tile to match it.
2. **THE STEP-8 FRAME AND THE PAGE FRAME DRAW DIFFERENT COLUMNS FOR ONE COMPONENT.**
   Recorded in full in `CR-087-p101`'s CONTRADICTIONS. Page 108's prose — *"the same
   component with the same bands in the same order"* — is the half that can be built;
   the two frames' column sets cannot both be.
