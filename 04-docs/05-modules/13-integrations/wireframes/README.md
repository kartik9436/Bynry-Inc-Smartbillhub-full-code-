# CR-069 wireframes — one PNG per frame of *The Integrations Surface* pack

**Source:** the PO's upload *The Integrations Surface* (22 pages, 41 frames), 2026-09-03. Rendered at 110 dpi with pymupdf, each frame cropped from its own header bar down to the line above its `▸ CODE FOR FRAME NN.N` bar, stitched across a page break where the pack's print layout cut it, and quantised to 64 colours. Total on disk ≈ 0.8 MB.

**These are the layout authority for the CR-069 screens** (PO ruling 2026-09-03: *"for Cr68, 69 and 70 - you will have to ensure you refer to screenshot we build and not just r10"*). `08-screen-layouts.md` says which frames draw each screen and where a frame loses to a rule; `09-component-inventory.md` names the pieces. The frame numbers are the pack's own, kept verbatim, so a sentence in an epic can cite `frame 51.2` and be found here as `frame-51-2.png`.

**The titles below are the pack's own header text, read out of the PDF** — not a description written from memory. An earlier version of this table was hand-written and had six of them wrong; the screen column is taken from `08-screen-layouts.md`.

⚠ A frame that crossed a page break (two numbers under *pack pages*) carries a hairline seam where the print cut fell, and a line of text may be clipped there. That is the pack's pagination, not the design. **A frame is layout, copy, flows and states only** — the pack's code bars were deliberately not captured, and its mono header bar, right-hand badge and 25.1's category switch are the pack's own chrome, not the product's.
