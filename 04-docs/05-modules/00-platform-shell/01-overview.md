# Module 0 — platform-shell

The build-once layer every feature consumes: app shell (collapsible sidebar, topbar with global search + notifications bell), table framework (B9 IS-2…IS-6, IS-9), forms & wizard framework, A18 states + toasts, i18n readiness + user preferences (column persistence), RBAC UI gating.
**Owns:** no domain tables; `user_preferences` storage only. **Screens:** shell chrome; conformance surfaces everywhere.
**Epics:** EP-SHL-01…06 (wave 0).
