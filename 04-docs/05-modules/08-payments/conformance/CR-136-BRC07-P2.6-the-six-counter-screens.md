## THE ONE DEFECT THE BROWSER FOUND, AND NOTHING ELSE DID

`tsc`, 26 unit cases, 9 tab cases and every gate passed over it.

`counter_list_totals` answers `taken_today`, `taken_today_payment_count` and
`difference_this_week` with **null** unless the caller sends `as_of`. That is
`BR-TEN-043` — nothing under `apps/payments/` may read a wall clock, because a
server clock decides a business day in the SERVER's timezone — and the server
marks the absence `totals_unavailable: "as_of_missing"`.

**This screen was not sending `as_of`, and its tiles read
`totals?.taken_today ?? "0"`.** So a supervisor opening the Counter tab was
told **$0.00 was taken today** over a blank payment count, when what the server
had said was *"nobody told me which day"*. That is `DEF-127`'s shape — *a
figure nobody filled rendering as a figure somebody counted*.

Fixed in `4f18b9873`, in three parts, and all three are needed: the fields are
typed `| null` so `?? "0"` cannot be written again without a type error saying
why; the list sends `as_of = todayInZone(tenantTimeZone)`; and a null figure
draws an em-dash over *No day chosen*. Confirmed in the browser afterwards —
the tile now reads `0 payments` where it read a blank.

## The two contracts these screens need from `P2.1`–`P2.3`

Both are written here and on the CR's `P2.6` row rather than said in a chat
that does not survive (hard-won law 10). **The API lane chose the same field
names independently** — `counters_api.py`'s own comment reads *"`rows`, NOT
DRF's `results`, AND THE SCREEN LANE'S NAME WINS"* — so the two met.

1. **A counter resolves by its CODE.** 3·2's address is drawn as
   `/:tenant/payments/counter/CTR-260921-DW` while every write is drawn as
   `POST /counters/{id}`. Both cannot be true of one value, and **B14 rule 31
   decides it**: an address bar is the most visible field a screen has.
2. **`GET /counters` accepts `f.mine=1`.** It is the only way a page head can
   ask *is MY till open?*, which is the second of 2·1 ①'s two states.
   `uq_counter_sessions_open_owner` guarantees the answer is one row or none.
