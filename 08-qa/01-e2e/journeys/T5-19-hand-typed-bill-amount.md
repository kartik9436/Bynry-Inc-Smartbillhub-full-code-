**Intent.** Hand-typed amounts NEVER exist on any bill (BR-BIL-019/020, NFR-19): computed amounts are never hand-editable (BR-BIL-023), ad-hoc bills draw lines ONLY from rules and charge codes, and even theft/penalty money enters as assessed READS priced by the engine plus configured charge codes. This journey proves the absence of the path — in the draft UI, in every wizard, and at the API — because a single free-typed dollar breaks reproducibility of every total downstream.

**Fixture.** Tenant brazos-bend · draft run RUN-2607-A (draft for ACC-1042 showing computed lines totaling $97.41 pre-issue — money-triples row `flat,cycle,full`) · charge code TAMPER $500.00 configured (the `flat,penalty` dataset rows price assessed reads + TAMPER 500.00 non-taxable per BR-BIL-019).

**Fixture amendment (2026-08-22, CR-014 · DEF-556).** Seeded by `seed_journey_fixture.seed_t5_19`. The draft moves off **ACC-1042 / RUN-2607-A** — a July run on the signed cast's account — to **ACC-2519** on an August cycle of its own. The **97.41** computed pre-issue total is the load-bearing part and is unchanged, and the TAMPER charge code is configured (its amount, see below); the seeder refuses if the draft prices anything else, or if the run reached `issued` (an issued bill is a different assertion from a draft). ⚠ **AND THE TAMPER AMOUNT IS $250.00, NOT THE $500.00 THIS PARAGRAPH QUOTES — DEF-563.** Two ratified sources disagreed (EP-RAT-03 §4 $250.00 vs the billing workbook's WE-11 $500.00) and the **PO ruled $250.00 on 2026-08-10**, making it the PLATFORM default; `seed_demo`'s own note records that the workbook's 500.00 *"is not a second default — it is the WE-11 worked example and stays there"*. This paragraph predates that ruling. The fixture leaves a seeded tenant's TAMPER row EXACTLY as the platform wrote it and never overwrites a ruled figure to satisfy a journey. **What this journey asserts is unchanged:** BR-BIL-019 — money enters by a CONFIGURED code and no door lets a human type a dollar. Which amount the code carries is not what it tests.
